# Documentation

Find the document by what you want to do. Every task a developer needs should be possible from these documents alone, without reading the code ([ENGINEERING.md](ENGINEERING.md), section 7).

## I want to…

| …do this | Read |
|---|---|
| Set up and run the project for the first time | [README](../README.md#quickstart), then [OPERATIONS.md](OPERATIONS.md) |
| Start, stop or reset the stack; open a UI; know which port is what | [OPERATIONS.md](OPERATIONS.md) |
| Fix something that went wrong (a job stopped, a check failed, a 403) | [OPERATIONS.md, Troubleshooting](OPERATIONS.md#troubleshooting) |
| Bring live or recorded data into the lakehouse | [OPERATIONS.md, Common tasks](OPERATIONS.md#common-tasks) |
| Know what a topic, table or column contains | [DATA_MODEL.md](DATA_MODEL.md) |
| Query the data, or check that nothing was lost or duplicated | [DATA_MODEL.md](DATA_MODEL.md#querying) |
| Understand the Wikimedia events themselves | [DATA_SOURCE.md](DATA_SOURCE.md) |
| Write code that fits the project | [ENGINEERING.md](ENGINEERING.md) |
| Open a pull request, read a CI failure, get a review or another review | [CI.md](CI.md) |
| Review a pull request | [CODE_REVIEW.md](CODE_REVIEW.md) |
| Know branch names, commit style and how a merge is decided | [CONTRIBUTING.md](../CONTRIBUTING.md) |
| Understand why the system is built this way | [DESIGN.md](DESIGN.md), then the [ADRs](adr/) |
| Record a significant decision | [adr/README.md](adr/README.md) |
| See what is done and what comes next | [ROADMAP.md](ROADMAP.md) |
